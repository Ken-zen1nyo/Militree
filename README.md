　**Militree シリーズ** は、CSVデータから複雑な部隊組織や人事データを読み込み、直感的なツリー形式で可視化するブラウザベースの組織図ビュアー・部隊管理ツール群です。

* **Militree (無印)**: 単一CSVから基本的な部隊ツリーと幕僚レイアウトを描画するシンプルビュアー。
* **Militree+**: 複数CSVの統合機能、左右のダブルサイドバーによるリアルタイム出欠（事故・現在員）集計機能を追加した運用強化版。
* **Militree++**: 顔写真表示、個人の「目標」「達成状況」の可視化・検索に対応した総合部隊マネジメント版。

## ✨ Militree++ の主な機能

* **📂 複数CSVファイルの一括読み込み**
    * 中隊ごとに分割されたCSVファイルを複数同時に選択・読み込み、1つの大きな組織図として自動的に結合・描画します。


* **🖼️ 個別顔写真の表示**
    * 隊員の顔写真をノード内に縦並びで表示します。画像未登録時や読み込みエラー時は自動でシルエットアイコン（SVG）が表示されます。
    * 画像ファイルは `./images/` フォルダへ配置し、CSVにはファイル名（例: `sato.jpg`）を指定するだけで自動補完されます。


* **🎯 個人の「目標」と「達成状況」の管理**
    * 各隊員の目標や進捗状況をノード内に表示。会議や面談時の進捗確認に活用できます。


* **🔍 強力な検索とフォーカス機能**
    * 氏名、役職、部隊名、不在理由、目標テキストなどから対象者を瞬時に検索し、該当部隊へズームします。
    * 右クリックメニューから「この部隊をルートとして隷下を表示」を選ぶことで、特定の中隊や小隊だけを切り出して表示可能です。


* **📊 リアルタイム人員・出欠・目標集計（左右のサイドバー）**
    * **シングルクリック（右サイドバー）**: 配下を含む組織全体の「部隊規模（総員・実員・欠員・事故・その他）」「階級区分」「軍種別」「男女別」および「全員の目標・達成状況リスト」を一覧表示します。
    * **ダブルクリック（左サイドバー）**: 選択した部隊の「総員」「事故」「その他」「現在員」のほか、不在者や該当者の氏名・理由の一覧を部隊名付きで確認できます。


* **👁️ ノード内表示のカスタマイズ**
    * 画面上部のチェックボックスで、**顔写真・役職・軍種・階級・氏名・性別・不在・備考・目標・達成・集計**の計11項目をワンクリックで自在にON/OFFできます。


* **💾 SVGエクスポート**
    * 現在表示されている組織図を高品質なSVG画像形式でダウンロード・保存できます。

## 🛠️ 動作環境・依存ライブラリ

本ツールはウェブブラウザ上で動作します。HTMLファイルと同一ディレクトリ（または指定パス）に以下のライブラリが必要です。

* **[GoJS](https://gojs.net/)** (`./library/go.js`): 組織図の描画エンジン
* **[Papa Parse](https://www.papaparse.com/)** (`./library/papaparse.min.js`): 高速なCSVパース用ライブラリ

## 📝 CSVデータのフォーマット

読み込ませるCSVファイルは、以下のカラム名（ヘッダー行）を**完全に一致**させる必要があります。

### 必須ヘッダー（1行目）

```csv
番号,部隊コード,部隊名,上級部隊コード,配置区分,役職,所属区分,軍種,階級,氏名,性別,備考,不在,理由等,その他,写真,目標,達成状況

```

### 各カラムの役割

* **番号**: メンバーの一意のID（集計時に実員を計算するためのキー）
* **部隊コード** *(必須)*: ノードの識別子。半角英数字推奨（例: `1i`, `1Co`）
* **部隊名**: 画面に表示される部隊の名称
* **上級部隊コード**: 親部隊の「部隊コード」。一番上のトップ部隊は空欄、または「なし」とします。
* **配置区分**: `assistant` / `スタッフ` / `補佐` と入力すると親部隊の横（幕僚位置）に配置されます。
* **役職**: 役職名（例: 連隊長、中隊長、情報係）
* **所属区分**: `主務`, `兼務`, `欠員` などを指定。（「兼務」「欠員」は実員集計から除外されます）
* **軍種**: `陸`, `海`, `空`, `統`, `内` など
* **階級**: 階級名（例: 1佐、曹長、事務官）。「幹部・准曹士・事務官等」を自動判別します。
* **氏名**: 氏名（欠員の場合は「欠員」や「未定」）
* **性別**: `男` または `女`
* **備考**: 任意のテキスト
* **不在**: 留守や欠席の状況（例: `代休`, `年休`, `出張` など）
* **理由等**: 不在の具体的な理由
* **その他**: 事故以外の特記事項（左サイドバーの「その他の内訳」に表示）
* **写真**: 画像ファイル名（例: `sato.jpg`）。`./images/sato.jpg` を自動読み込みします。空欄時はシルエット表示。
* **目標**: 個人の目標（例: `体力検定1級`, `資格取得` など）
* **達成状況**: 目標の進捗や結果（例: `80%`, `達成`, `実施中` など）
