# Militree シリーズ (部隊組織図＆総合人員・目標管理ツール)

　**Militree シリーズ** は、CSVデータから複雑な部隊組織や人事データを読み込み、直感的なツリー形式で可視化するブラウザベースの組織図ビュアー・部隊管理ツール群です。

　最新の **Militree++** では、外部ライブラリをHTML内部に完全統合し、ネットワークがない**クローズド環境でも単体動作**するようになりました。さらに、現在読み込んでいる部隊データをHTML内部に定着させて出力する「データ込み保存機能」を搭載。完成したHTMLファイルをダブルクリックするだけで、一瞬で顔写真付きの組織図を展開できる究極のポータビリティを実現しています。

## ✨ Militree++ の主な新機能

* **💾 データ込み保存（スナップショット作成）**
    * 読み込んだCSVデータと現在の画面設定（画像パス等）をHTML内部に埋め込み、新しいHTMLファイルとして保存できます。
    * 保存されたファイルは、次回からCSVを読み込ませる手間なく、**開いた瞬間に組織図が自動展開**されます。朝礼や会議用の資料として配布・共有するのに最適です。


* **🖼️ 画像パスの動的指定 ＆ オフライン対応**
    * 画面上部の「画像フォルダ」入力欄から、画像の参照先をいつでも自由に変更可能（例: `./images/` や共有ドライブ `C:/Militree/photos/` などフルパスも可）。
    * 画像ファイルが見つからない場合は、ローカル（オフライン）でも確実に表示されるSVGシルエットアイコンが自動で適用されます。


* **🎯 個人の「目標」と「達成状況」の管理**
    * 各隊員の目標や進捗状況をノード内に表示。検索機能で特定の目標やステータスを持つ隊員を瞬時に探し出し、ズームすることが可能です。


* **📦 完全なポータビリティ（依存ファイルなし）**
    * 動作に必要な描画エンジン（GoJS）やCSVパーサー（PapaParse）のコードがすべて1つのHTMLファイルに組み込まれているため、外部フォルダへのリンク切れ等のトラブルが一切発生しません。

## 📝 CSVデータのフォーマット

読み込ませるCSVファイルのヘッダー行（1行目）は以下の順序・名称に**完全に一致**させる必要があります。

```csv
番号,部隊コード,部隊名,上級部隊コード,配置区分,役職,所属区分,軍種,階級,氏名,性別,備考,不在,理由等,その他,写真,目標,達成状況

```

### 各カラムの役割（抜粋）

* **配置区分**: `assistant` または `スタッフ` と入力すると親部隊の横（幕僚位置）に配置。
* **所属区分**: `主務`, `兼務`, `欠員`。（「兼務」「欠員」は実員集計から除外）
* **不在 / 理由等 / その他**: 出欠状況や特記事項（左サイドバーに自動リストアップされます）。
* **写真**: 画像ファイル名（例: `sato.jpg`）。画面上のパス設定と組み合わせて自動で読み込まれます。
* **目標 / 達成状況**: 個人の目標と進捗結果。

## 🚀 基本的な使い方と運用フロー

### 1. ベースとなる組織図の作成

1. `Militree++.html` をウェブブラウザ（Edge, Chrome, Firefox等）で開きます。
2. 画面上部の **「画像フォルダ」** 欄に、写真が保存されている場所（例: `./images/` や `C:/photos/`）を入力します。
3. **「ファイルを選択」** ボタンから、各中隊・小隊のCSVデータを**まとめて一括選択**して読み込みます。

### 2. データ込み保存（配布・共有用ファイルの作成）

1. 組織図が完成したら、画面左上の緑色の **「データ込み保存」** ボタンをクリックします。
2. 任意のファイル名（例: `第1連隊_朝礼用_20260909.html`）を付けて保存します。
3. **これで「データ内蔵済みの完成版HTML」が生成されます。**

### 3. 保存したファイルの活用

* 出力されたHTMLファイルは、**ダブルクリックしてブラウザで開くだけ**で、即座に顔写真・目標・出欠込みの組織図が表示されます。
* ネットワークから完全に切り離されたクローズドなPCや、USBメモリ内からでも高速に動作します。
* 表示情報の切り替え（顔写真・目標・集計などのON/OFF）や検索機能、左右サイドバーでの集計機能もすべてそのまま利用可能です。
